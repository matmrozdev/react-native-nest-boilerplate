# Mobile application

Expo SDK 57 React Native client with protected Expo Router navigation,
React Query, secure session restoration, authentication screens, Unistyles,
and reusable UI components.

Copy `.env.example` to `.env`, set `EXPO_PUBLIC_API_URL`, and run:

```sh
pnpm start
```

Use `10.0.2.2` instead of `localhost` for an API running on the Android host.
Change the example bundle identifiers, scheme, icons, and splash assets in
`app.json` before publishing a derived application.
